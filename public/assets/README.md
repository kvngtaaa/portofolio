# Project Screenshots Directory (`public/assets/`)

Folder ini digunakan untuk menyimpan screenshot asli dari web project yang kamu bangun.

## Format & Nama File yang Digunakan:

| File | Project Terkait | Dimensi Rekomendasi |
| :--- | :--- | :--- |
| `aga-web.png` | **Asisten Generatif Agrikultur (AGA)** — Smart Farming Decision Support | 1280 x 800 (16:10) atau 1920 x 1080 |
| `agrinova-web.png` | **AgriNova Solutions** — IoT Telemetry & AI Crop Advisory | 1280 x 800 (16:10) atau 1920 x 1080 |
| `trigobalindo-web.png` | **PT Trigobalindo Id** — Corporate Profile Platform | 1280 x 800 (16:10) atau 1920 x 1080 |
| `transtrack-web.png` | **Transtrack.id** — Enterprise Fleet Telematics QA Portal | 1280 x 800 (16:10) atau 1920 x 1080 |

## Cara Mengganti dengan Screenshot Asli Kamu:
1. Ambil screenshot web asli kamu (misal ukuran layar desktop 1280x800 atau 1920x1080).
2. Simpan file dengan nama yang sesuai di folder ini (`public/assets/aga-web.png`, `agrinova-web.png`, dst).
3. Browser Frame Mockup akan secara otomatis memuat screenshot aslimu secara responsif lengkap dengan bingkai macOS, 3 dot traffic lights, address bar, dan efek hover mengangkat yang smooth!
